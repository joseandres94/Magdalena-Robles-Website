# Magdalena Robles — Fashion Designer Website

Angular 17 project for Magdalena Robles, fashion designer & pattern maker based in Almería.

## Quick Start

```bash
npm install
ng serve
```

Open [http://localhost:4200](http://localhost:4200)

## Build

```bash
ng build
```

## Structure

```
src/
  app/
    core/           # Layout, services, models
    shared/         # Reusable components
    features/       # Page components (lazy-loaded)
    data/           # Static data & brand content
  styles/           # Global SCSS tokens & utilities
```

## Tech Stack

- Angular 17 (standalone components)
- TypeScript strict mode
- SCSS modular
- Angular Animations
- Angular Router (lazy loading)
- Reactive Forms
